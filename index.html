Editing model

  
One project can start with imported media, generated motion or a captured take. The editor owns the sequence. Capture extensions produce assets on a shared source clock and hand them to the normal media bin.

  
Tracks, anchoring and synchronized components
Use an explicit primary track with optional ripple. Overlay tracks keep their compositing order. Titles and graphics can attach to a shot so they follow moves and ripple edits. A take appears as one clip by default. Expand its component rows in place for screen, camera, microphone, system audio, pointer and approved key cues. Toggle visibility or mute per clip instance; trims and split boundaries inherit the parent mapping. Detached instances become ordinary timeline clips with explicit sync offsets in the Rust design.

Motion graphics
Titles, transforms and effects have typed parameters. Motion lives at the clip in the inspector with keys visible on its timeline lane. A graph and curve editor can grow from that same model when compositing needs it. The sample animates scale between two editable linear keyframes.

MCP and the Rust core
One revisioned command engine serves the editor, headless CLI and MCP stdio adapter. Tools read a snapshot or propose typed operations against a specific revision. Each proposal returns a change ID and affected objects. Render reads committed or draft state through the same evaluator. Submission freezes a draft for review. Accepting selected changes is one atomic commit and one undo step. Stale drafts require explicit rebase and review. Render previews have scoped artifact handles. Final delivery is a separate job requiring confirmation of the profile and destination.
MCP tool and structured-result contract

  
Recorder inheritance and sample limits
Recorder supplies the Signal UI palette and typography, exact inspector scope, non-destructive capture, time mapping and human draft review. This browser prototype uses generated sample takes and motion, local video import, an in-memory timeline and a simulated MCP adapter. Capture controls load samples. Audio playback, encoded delivery, detaching, retime curves and a native Rust app are future implementation work. Keyboard cues in this sample are synthetic.
